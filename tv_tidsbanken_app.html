Koppla ihop med Apple TV (Homey / pyatv)

Automatisk avstängning vid 00:00 & live-status

1. Homey Advanced Flow

När tiden når 00:00 eller barnet försöker tjuvtitta skickas ?event=time_up eller ?event=force_power_off till din Webhook-URL.

👉 NÄR Webhook mottagen → DÅ Apple TV: Pausa & Stäng av (HDMI-CEC släcker TV:n).

2. Python-skript (pyatv)

import asyncio, pyatv, requests

class TvListener(pyatv.interface.PushListener):
    def playstatus_update(self, updater, playstatus):
        requests.post("https://homey.local/api/webhook/atv_sync", json={
            "state": str(playstatus.device_state),
            "title": playstatus.title
        })

async def main():
    atvs = await pyatv.scan(asyncio.get_event_loop(), timeout=5)
    atv = await pyatv.connect(atvs[0], asyncio.get_event_loop())
    atv.push_updater.listener = TvListener()
    atv.push_updater.start()
    await asyncio.Event().wait()

asyncio.run(main())
